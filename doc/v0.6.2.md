## 二、逐项改动明细

### P1 多词搜索修复（功能）
- 改动点：`packages/db/src/prompt.ts`（新增 `buildFtsPhraseQuery` 纯函数 + `search()` 接入）；`packages/db/src/index.ts` 与桌面 shim 补充导出。
- 实现思路：空白分词 → 每词独立 `"` 转义引号包裹 → `AND` 连接；无有效 token 返回 null 跳过 FTS 谓词。
- 影响范围：桌面/CLI/自托管 Web 共用的 `PromptDB.search` 关键词过滤（召回严格扩大，语义向用户直觉对齐）；无 schema、无迁移、无 IPC/契约变化。
- 兼容性：单词与特殊字符安全行为逐条测试锁定；纯空白输入从"空结果"修正为"等同无关键词"（行为修正已在 CHANGELOG 声明）。

### E1+E2 三视图共享批量条（体验，含断线修复）
- 优化位置：表格视图批量条；画廊（图片）视图；卡片（默认）视图列表面板。
- 调整方案：
  - 新增 `PromptBatchActionBar.tsx`（共享批量条：已选 n / 共 m 项、标签、收藏、移动文件夹菜单、删除、清除选择）与 `usePromptBatchSelection.ts`（选择状态 hook，从 TableView 原逻辑等价平移）。
  - TableView 接共享件并接通 `onBatchTags`（断线复原）；`PromptViewContainers` 的 `PromptTableActions` 接口补声明。
  - 画廊卡片新增复选框（抽出 `PromptGalleryCard.tsx`），批量操作后清除时序与表格一致。
  - 卡片视图 store 多选（原有 Ctrl/Shift 逻辑不动）补可见批量条，复用既有 store batch handlers。
  - 删除 `t(...) || '硬编码中文'` 兜底 4 处；新 key `prompt.selectedOfTotal`、`prompt.deselectPromptRow` 落 7 locale。
- 用户实际收益：不必切换视图即可批量；标签入口恢复且视图全覆盖；"选了多少 / 总共多少 / 如何退出"一目了然。
- 输入输出不变承诺：持久化调用链、handler 签名、QuickTagModal 语义零改动；纯表现层。
- 附带收益：TableView 1046→875 行、GalleryView 412→287 行（卡片组件拆分），改善遗留巨文件债务。
- 产品级修正：批量条关闭按钮标签 `common.cancel` → `prompt.clearSelection`（"清除选择"）。起因：内联编辑集成测试暴露 "Cancel" 双按钮同名歧义；新标签语义也更准确。

### E3 启动文件夹偏好（体验，响应 #74）
- 优化位置：设置页-常规-启动区；App 冷启动流程。
- 调整方案：settings store 新增 `startupFolderMode`（default/last/pinned）+ `pinnedStartFolderId` + `lastActiveFolderId`；`selectFolder` 记录激活文件夹；新 hook `useStartupFolderRestore` 在 folders 首次加载后恢复一次（经手动选择同一 action 路径，解锁/刷新语义完全复用）；设置页模式三选一下拉 + pinned 目标文件夹下拉；8 个 `settings.*` 新 key 落 7 locale。
- 用户实际收益：深文件夹工作流冷启动直达工作位置；固定文件夹模式支持"每天开工都在同一个分类"。
- 输入输出不变承诺：默认 mode=default 与 0.6.1 行为逐位一致；字段仅存 renderer localStorage 偏好，不进 DB/备份/同步负载；目标文件夹被删除时静默回落，坏值经 merge normalizer 清洗。
- 范围偏差说明：右键"设为启动项"改为设置页 pinned 下拉承载（侧栏文件夹无 context menu 先例，新增右键容器超出本期增量边界），记录于 implementation.md。

### E4 编辑弹窗次要信息折叠（体验，响应 #76）
- 优化位置：CreatePromptModal / EditPromptModal 的"来源""备注"两个次要字段组。
- 调整方案：新增 `ui/CollapsibleSection`（hidden 切换、不卸载内容、aria 完备）；字段组提取为共享组件 `PromptSourceNotesFields`（顺带清除两处 `t() || "English"` 死兜底）；默认折叠，展开记忆为弹窗内会话级。
- 用户实际收益：折叠态下系统/用户提示词编辑区可见面积显著增大（窄窗尤其明显）；非必要信息不再干扰新手。
- 输入输出不变承诺：字段顺序、受控 state、校验、提交 payload 全部不动；组件测试用对抗样本（尖括号/emoji/破折号）验证折叠→展开→保存值逐字一致。
- 工程合规：初版内联接入触发 `lint:file-size` 对遗留巨型文件 EditPromptModal 的"禁止膨胀"门禁（1836>1830）→ 改用提取共享子组件方案后门禁通过且文件净瘦身。

# PromptHub v0.6.3（基于上游 v0.5.9）

2026-10-01 · fork 自主迭代线 0.6.0→0.6.3 汇总。完全向后兼容：无数据库迁移、无破坏性变更，默认行为与 v0.5.9 一致。

## 新功能

**批量管理**
- 批量标签：多选提示词统一加/删标签，交集展示、按条回滚、支持 Ctrl/Shift 范围选择
- 表格/画廊/卡片三视图共享批量操作栏：标签、收藏、移动、删除、清除选择，显示"已选 n / 共 m"；画廊卡片新增多选框

**数据安全**
- 规则备份导入冲突保护：不再覆盖外部编辑过的规则、不再用空备份清零非空目标，冲突保留本地历史并输出结构化摘要
- 窗口级拖拽恢复：把备份 .zip 拖到窗口任意位置即可恢复，走统一预览确认流程

**搜索**
- 多词搜索按词匹配（AND），不再要求词相邻；特殊字符防护完整保留
- Ctrl+F（mac ⌘F）直达搜索框并全选关键词

**启动与导航**
- 启动文件夹偏好：冷启动自动进入上次或固定文件夹（默认关闭）；恢复/失效有提示，设置页标注已删除的固定项

**编辑弹窗**
- 来源、备注收入默认折叠分组，核心编辑区更大；折叠不影响保存
- 文本类参考媒体区提至主流程，就地标注真实限制（本地文件 ≤20MB、URL 图片 ≤10MB，与强制值同源）
- 标签管理：用量计数、按用量/名称排序、一键筛选直达列表

**引导**
- 备份区顶部三步指引卡：导出备份 → 新设备/回退版本安装 → 拖入或导入恢复（可折叠，状态记忆）
- 空列表归因：被筛选清空时提供"清除筛选"一键出路；空库时提供新建引导

## 修复

- 自托管 Web 分类保存必现 422（未携带 visibility 时按目标分类推断）
- 主密码设置/修改/解锁失败不再向用户弹原始英文报错，全部本地化
- 快速标签弹窗写失败回滚加固（显式快照回滚 + 保存中 Enter 竞态封锁）
- 规则工作区测试 Windows 兼容（临时目录改用跨平台路径）

## 升级说明

- 直接覆盖安装即可，无需迁移；换设备或回退版本请先导出全量备份
- 多词搜索结果会更全面（每个词仍须命中）
- 新增行为（启动文件夹、指引卡、折叠分组）默认关闭或保持原样

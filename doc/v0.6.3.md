## 二、逐项明细（优化位置 / 调整方案 / 用户收益）

### X1 空态引导
- **位置**：卡片/表格/画廊三视图空列表区。
- **方案**：新共享组件 `PromptListEmptyState`——有筛选（searchQuery/filterTags/selectedFolderId 任一）时显示归因文案+〔清除筛选〕一次复位三源；真空库时显示〔新建 Prompt〕（dispatch 既有 `shortcut:newPrompt`，与顶栏新建同路径）。
- **收益**：消灭"搜了没有→不知哪儿卡住"死胡同；新手首次打开有行动指引。
- **输入输出不变**：全部走既有 setter/事件；kanban 未接入（记录为后续候选）。

### X2 媒体上传提层 + 限制提示
- **位置**：编辑弹窗媒体区（原藏 More Settings 深处）；上传按钮文案。
- **方案**：文本类 `renderReferenceMediaSection()` 移至主流程（用户提示词之后，不展开"更多设置"即可见）；限制值（本地 20MB / URL 10MB / 格式白名单）收敛到 `packages/shared/constants/media-limits.ts` 单一事实源，主进程 image.ipc 改 import 同值常量（行为零变化），弹窗 hint 文案插值自常量。
- **收益**：带图 prompt 不用翻三层找入口；上传失败前就知道约束。
- **输入输出不变**：上传/保存/校验链路未动；Create 弹窗核查后确认媒体本已在主流程，仅补 hint。

### X3 安全错误人话化
- **位置**：SecuritySettings 5 处 catch（原 `showToast(e?.message || fallback)` 英文优先透传）。
- **方案**：纯函数映射器 `getSecurityErrorCopy`——主进程 security.ipc 5 条错误枚举 → 本地化行动提示；未知错误 → 通用文案 + 原始信息进 console。PrivateFolderUnlockModal/FolderModal 核查后已是全 i18n，未动。
- **收益**：非英语用户看得懂"哪里失败、下一步做什么"。
- **契约变更（有意）**：既有测试断言"未知错误原样透传"与新目标冲突，按新契约改写（断言通用文案 + console 保留 + toast 无英文原文）。

### X4 Ctrl+F 直达搜索
- **位置**：App 全局 keydown + TopBar 搜索框。
- **方案**：localShortcuts 未命中该组合键时 Ctrl/Cmd+F 兜底 dispatch 既有 `shortcut:search`；handleSearch 补 `select()`（聚焦即全选可改词）；prompt 上下文 placeholder 换 `header.searchWithShortcut`（⌘F/Ctrl+F 按平台）。
- **收益**：搜索零跳数；快捷键可发现。
- **输入输出不变**：搜索逻辑与用户快捷键配置系统完全不动，用户占用 Ctrl+F 时兜底让位。

### X5 启动文件夹恢复反馈
- **位置**：0.6.2 的 `useStartupFolderRestore`（原全程静默）。
- **方案**：hook 改依赖注入 `notify?`（App 传 showToast）——恢复成功 info toast 含文件夹名；目标缺失 warning toast；设置页 pinned 下拉对失效 id 显示"（已不存在）"项。default 模式保持零提示。
- **收益**：新功能可感知、失效可自助排查。
- **输入输出不变**：选择路径与持久化语义不动。

### X6 标签管理完善
- **位置**：TagManagerModal（核查发现原**连用量数字都不显示**，缺口比候选清单预估更大）。
- **方案**：用量计数徽标（prompt/skill 双模式）；排序（默认用量降序/升序/名称）；prompt 模式行内〔查看〕→ `setFilterTags([tag])`（新 setter）+ 关弹窗直达筛选，筛选中标签高亮 ✓。
- **收益**：标签从"只能看"变"管理→定位→处理"闭环。
- **输入输出不变**：改名/删除/存储链路未动。

### X7 备份迁移指引卡
- **位置**：设置页备份区顶部。
- **方案**：三步静态指引卡（导出 → 新设备/回退安装 → 拖入或导入恢复），折叠偏好持久化 `backupGuideCollapsed`（坏值归一）；卡内不放重复按钮（面板下方即有导出/导入，避免双入口歧义）。
- **收益**：数据自救路径在 UI 内直给，"救命贴"类问题从源头减少。
- **输入输出不变**：纯展示 + 既有动作邻近呈现。

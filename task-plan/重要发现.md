# 发现记录: .git 瘦身与发布脚本

## 研究发现

### .git 体积构成（实测）
- `.git` 总 689.4 MB，其中 objects 582 MB（84%）
- loose objects 598 MB —— 悬空对象滞留的直接证据（count-objects -vH）
- 最大 blob TOP：`PromptHub-main_备份_20261001_03时24分.zip` 457.4 MB、`…_00时57分.zip` 124.7 MB
- 仓库合法历史最大对象仅 4.5 MB（docs/screenshots 截图）→ 历史本身干净

### 病因链
1. `git stash push -u` 会把工作区**未跟踪文件**（含根目录两个备份 zip）整体存成 blob
2. `stash drop` 后这些 blob 失去引用 → 成为悬空 loose objects
3. `gc` 默认保留 2 周内的不可达对象 → 长期占空间

### 瘦身验证数据
- 执行前：`.git` 689.4 MB / loose 598 MB
- 执行后：`.git` 82.8 MB / count-objects: in-pack 29011, size-pack 82.24 MiB, garbage 0
- 净减 ~606 MB（-88%）

## 技术决策依据
- 镜像源 ELECTRON_MIRROR=npmmirror + ELECTRON_BUILDER_BINARIES_MIRROR：本机直连 GitHub 下载二进制超时风险高
- 无证书跳过签名：electron-builder 日志确认 "signing is skipped"，开发机无私签证书属预期
- 版本号联动：脚本读 package.json version，bump 后产物目录自动跟随（如 发布版\0.6.1\）

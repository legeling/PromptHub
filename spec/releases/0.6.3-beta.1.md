## Scope

Root, Desktop, standalone CLI, Web, Worker and Mobile build identities use
0.6.3-beta.1. Shared packages retain independent versions. All seven README
locales distinguish this preview candidate from stable downloads. The docs index
needs no change; generated website metadata still selects 0.6.2. No screenshot
is regenerated or claimed as evidence. The existing cloud account locale changes
cover all seven languages. No Cloud backend or production deployment is included.

The exact CHANGELOG.md version section owns public notes. This release includes
#249 Skill startup recovery, migration-preserved files in workspace restoration,
and the current browser Cloud sign-in source changes. Cloud UI keeps its existing
explicit build gate and is not advertised as a default exposed feature. Old diagnostic output and the
separate unsent SignPath correspondence draft are retained locally, not shipped.

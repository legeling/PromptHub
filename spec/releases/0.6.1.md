## Upgrade and rollback

This candidate includes the existing ordered historical Prompt workspace upgrade
and backup import changes. Ambiguous historical conflicts require explicit choices;
original data and pre-upgrade recovery material must remain available. Do not open
an upgraded profile with an older binary as a rollback method. Restore a compatible
pre-upgrade backup into an isolated profile and verify it before replacing data.
Reporter-specific old Windows profiles and nonempty historical MCP/Plugin archives
retain their documented acceptance limits; local synthetic fixtures are not those profiles.

Before publication, require the full final-candidate gate, all five build jobs,
macOS signing/ticket/Gatekeeper verification, Windows x64 two-start upgrade smoke,
and matching installer/update-manifest hashes. Publication and stable-channel
promotion proceed only after these checks succeed.

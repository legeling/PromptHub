# PromptHub 0.6.0 Release Record

## Release

- Version: `0.6.0`
- Tag: `v0.6.0` (not created)

## Preparation Scope

- The first release candidates used `0.6.0-beta.1` and `0.6.0-beta.2`. The
  current draft uses `0.6.0` across Root, Desktop, CLI, self-hosted Web,
  Cloudflare Worker, Mobile, and Expo metadata. The version identity does not
  promote the GitHub draft or change the public stable channel.
- Private shared packages retain their independent `0.1.0` package versions.
- Public website badges, introductions, and download URLs continue to point to
  the latest explicit stable release record, currently `0.5.9`.
- Localized README stable labels and download links remain on `0.5.9` until
  signed artifacts and other distribution outputs have been published.
- The accepted storage target is SQLite authority for structured records,
  relationships, annotations, version metadata, and settings; the filesystem
  owns actual packages, attachments, media, and required historical contents.
  The earlier file-first/rebuildable-SQLite model is not the selected 0.6.0
  baseline. Conversion and upgrade acceptance remain in progress under
  [the foundation requirements](../changes/active/foundation-integrity-redesign/specs/foundation/spec.md#fr-foundation-003-data-ownership-and-invariants).
- Main/Core ownership of renderer persistence, secret isolation, restore/root
  recovery, and consistent portable snapshots must satisfy that same boundary.
  This release record does not claim migration or release acceptance is complete.
- The shared SQLite migration foundation is verified against tagged `v0.4.7`,
  `v0.4.8`, `v0.5.1`, and `v0.5.2` fixtures. Historical issues #89, #97, and #98
  remain in progress until their exact path/portable/upgrade-snapshot application
  fixtures converge under `legacy-upgrade-recovery-audit`.

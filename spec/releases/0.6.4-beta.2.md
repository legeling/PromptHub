# PromptHub 0.6.4-beta.2

Apple 芯片 Mac 手动安装预览候选。解压 ZIP，将 PromptHub.app 移入应用程序目录后打开。

- 快速添加可从带有 `{CHARACTER}` 等前言的模型回复中提取唯一有效的标题和标签。解析失败时，已保存的正文保留，可单独重试。
- 延续 beta.1 的旧库迁移修复，保留受管 Skill 和链接导入的外部目录绑定。

Apple silicon Mac preview candidate for manual installation. Unzip the archive and move PromptHub.app to Applications. Quick Add recognizes a single valid result following a braced preamble and supports retrying the saved entry. This build retains the beta.1 migration fix for managed and externally linked Skills.

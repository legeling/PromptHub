# PromptHub 0.6.2

## Product

Delivery

## Status

Published stable on 2026-10-27: [GitHub release](https://github.com/legeling/PromptHub/releases/tag/v0.6.2), with 20 verified assets. Official website deployment is being verified.

## Scope

- Root, Desktop, standalone CLI, self-hosted Web, Cloudflare Worker and Mobile
  manifests use 0.6.2; Expo and the CLI runtime version match.
- Internal shared packages retain their independent versions.
- Public download links, seven language READMEs and generated website metadata select 0.6.2.
- Published tag commit: `6e43b17a9184d09e393a194cf8210cbe0ca25b56`.
  Failed candidates are preserved at `failed-release/0.6.2-0fbac670` and
  `failed-release/0.6.2-020847e7`.
- Independent CLI tarball is included in the GitHub release; no npm registry publication is implied.
- Product changes are maintained in the exact 0.6.2 section in CHANGELOG.md.
  The release includes unified local/remote workspace snapshots, manual refresh,
  Agent provider fixes, independent Antigravity desktop/CLI identities and nested
  GitLab repository Skill imports, historical IndexedDB startup recovery and
  safe image generation history deletion.
- Existing active changes retain their own scope and acceptance status. The
  official website uses the separate Cloud repository and Railway Web service;
  its production readback is required after publication.

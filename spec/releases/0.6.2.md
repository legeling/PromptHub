# PromptHub 0.6.2

## Product

Delivery

## Status

Release candidate under verification on 2026-10-27. Not published; no release date assigned.
The latest published stable remains [0.6.1](0.6.1.md).

## Scope

- Root, Desktop, standalone CLI, self-hosted Web, Cloudflare Worker and Mobile
  manifests use 0.6.2; Expo and the CLI runtime version match.
- Internal shared packages retain their independent versions.
- Public download links, stable badges and generated website release metadata
  continue to select 0.6.1. No installer, image, tag or deployment is published.
- Seven language README entry points identify 0.6.2 as development until the
  published release and its download assets are verified.
- Product changes are maintained in the exact 0.6.2 section in CHANGELOG.md.
  The release includes unified local/remote workspace snapshots, manual refresh,
  Agent provider fixes and independent Antigravity desktop/CLI identities.
- Existing active changes retain their own scope and acceptance status. The
  official website uses the separate Cloud repository and Railway Web service;
  its production readback is required after publication.

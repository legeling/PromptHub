# Delta Spec

## Added

- `FR-001` Prompt 右键菜单新增“移动到...”入口。
- `FR-004` Prompt 列表/卡片视图的树选择遵循单分支手风琴：选中或重复选中某 Prompt 后，展开其自身与祖先链，其他有子节点的父分支自动收起（取消选中不改变折叠状态）。
- `FR-003` 全局备份文件拖放接管范围限定于携带文件的拖拽；Prompt 内部层级拖拽不得被全局层改写为 `copy`。
- 右键菜单触发的文件夹选择弹层必须列出全部文件夹并支持移出当前文件夹。
- Prompt 右键菜单新增“折叠全部提示词”入口，用于折叠当前可见提示词树中所有带子节点的 Prompt。
- `FR-001` Prompt 右键菜单新增“移动到节点”入口，用于将当前 Prompt 移动到另一个 Prompt 节点或根节点。

## Modified

- `FR-001` 单条 Prompt 的文件夹迁移不再只能依赖拖拽或表格批量移动。
- `FR-001` 单条 Prompt 的树节点迁移不再只能依赖拖拽，右键菜单也必须复用既有 `parentId/order` 层级语义。
- `FR-002` “移动到节点”在写入 `parentId/order` 的同时，将被移动 Prompt 及其所有后代的 `folderId` 同步为目标父节点的 `folderId`，确保文件夹视图中的层级关系不被 `folderId` 过滤压平。
- `FR-002` “移动到节点”移动到根节点时保持被移动 Prompt 自身的 `folderId` 不变。

## Scenarios

- `TEST-001`：当用户在任意 Prompt 视图中右键单条 Prompt 时，可以通过“移动到...”直接选择目标文件夹。
- `TEST-001`：当用户选择“移出文件夹”时，该 Prompt 的 `folderId` 被清空并立即反映到列表中。
- 当用户选择“折叠全部提示词”时，当前可见提示词树里所有有子节点的 Prompt 被折叠。
- `TEST-002`：当用户通过“移动到节点”选择另一个 Prompt 时，当前 Prompt 的 `parentId` 更新为目标 Prompt，且作为目标节点的末尾子节点。
- `TEST-002`：当用户通过“移动到节点”选择根节点时，当前 Prompt 的 `parentId` 被清空并移动到根层级末尾。
- `TEST-002`：“移动到节点”不得列出当前 Prompt 自身或它的后代作为可选父节点。
- `TEST-002`：当用户通过“移动到节点”选择另一个 Prompt 时，被移动 Prompt 所在文件夹立即变为目标父节点所在文件夹；其原有子节点也一并进入同一文件夹（2026-10 语义补充：解决文件夹视图按 `folderId` 过滤导致 `flattenPromptTree` 找不到父节点、层级被压平显示为平级）。
- `TEST-002`：当用户通过“移动到节点”选择根节点时，被移动 Prompt 的 `folderId` 保持不变（只解除父子引用），不得被误置入“无文件夹”。
- `TEST-002`：当被移动的子树带有后代时，后代 `folderId` 与 `parentId` 均与新父上下文一致，回到原文件夹视图中该子树不再残留。
- `TEST-003`：当用户把一条 Prompt 卡片拖到另一条 Prompt 卡片中间三分之一区域时，全局备份拖放层不得把 `dropEffect` 改成与 `effectAllowed=move` 冲突的 `copy`；目标卡片应接受原生 `drop` 并完成移动到节点。
- `TEST-004`：当展开父分支 A 后用户点击另一条 Prompt B 时，A 自动收起，B 的祖先链保持展开；取消选中（selected id 为空）不触发自动收起。
- `TEST-004`：当用户点击已被折叠的父分支 A（含子节点）时，A 展开；即使 A 已处于选中状态，再次点击 A 仍会展开，供用户从手动折叠状态恢复。

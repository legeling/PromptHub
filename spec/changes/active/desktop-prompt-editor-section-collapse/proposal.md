# Proposal: Prompt 编辑窗次要信息折叠

## Change Key
`desktop-prompt-editor-section-collapse`（v0.6.2 / E4，体验类，响应 GitHub #76）

## Why
#76（open，用户主动请求）：编辑 Prompt 弹窗字段密集，窄窗口/小屏下主要编辑区（系统/用户提示词）被来源、关联、备注等次要字段挤占，需要大量滚动。用户希望"非必要信息可折叠"。

## Scope
纯呈现层：编辑弹窗（新建与编辑共享表单结构，实现时确认组件归属）将次要字段包进共享可折叠区块；默认折叠"次要信息"组，用户展开后本次会话记忆。字段的渲染顺序、保存内容、校验、提交 payload 全部不动——用户输入输出零影响。

## Non-goals
- 不做字段配置自定义、不拆分巨型弹窗文件结构（仅加折叠容器；新逻辑落在小组件内控制行数）。

## 兼容与回滚
- 折叠只是容器视觉变化；展开态下与 0.6.1 渲染内容一致。
- 回滚：还原弹窗文件 + 删除折叠组件。
